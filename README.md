# 🐍 Питон в браузере (для уроков информатики)

Удобная и быстрая среда разработки на Python, которая запускается прямо в браузере. Создана специально для использования на уроках информатики в школах.

## ❓ Зачем это нужно
На школьных компьютерах часто нет прав администратора, чтобы установить полноценный Python или IDE. А обычные онлайн-компиляторы из интернета часто бесят: в них неудобно вводить данные через `input()` (постоянно выдает ошибки `EOFError`), нет нормальных подсказок и глаза устают от белого фона. 

Этот сайт решает эти проблемы:
- Когда программа просит `input()`, выскакивает обычное окошко браузера, куда спокойно вводишь данные.
- Есть умные подсказки (начинаешь писать `pri` — редактор сам предлагает `print`).
- Можно переключать темы оформления (тёмная, светлая, неоновая), чтобы не убивать зрение на уроках.

## ✨ Возможности
- 🚀 **Мгновенный запуск.** Код выполняется моментально прямо на устройстве пользователя (через технологию WebAssembly).
- 💡 **Умный редактор.** Подсветка синтаксиса, нумерация строк, автозакрытие скобок и подсказки по кнопке `Ctrl+Space`.
- ⌨️ **Удобное управление.** Нажимаешь `Ctrl + Enter` — код выполняется (не надо каждый раз тянуться мышкой к кнопке).
- 🎨 **Три темы на выбор.** Тёмная (по умолчанию), Светлая и Неоновая.
- 📊 **Статус-бар снизу.** Показывает, на какой строке и столбце находится курсор, а также статус движка.

## 🛠️ Как это работает (для любопытных)
Сайт не отправляет ваш код на сервер — всё считается прямо в браузере. Это значит, что он работает очень быстро и не нагружает школьную сеть.
- **Сам Python:** За это отвечает библиотека `Pyodide`. Это полноценный Питон, скомпилированный для работы в браузере.
- **Редактор кода:** Используется `CodeMirror`. Он делает всю красоту с подсветкой, нумерацией и автодополнением.
